# Secure Text Encryption and Decryption

## Overview

This project demonstrates secure text encryption and decryption using symmetric encryption with the `cryptography` library in Python.

## Project Structure

- **main.py**: The main entry point of the application.
- **encryption.py**: Contains functions for encrypting and decrypting messages.
- **key_management.py**: Handles key generation and storage.

## Installation
